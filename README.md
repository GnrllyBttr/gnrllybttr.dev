## 🎯 Overview

A nostalgic Windows 95-themed website serving as the home for GnrllyBttr's development tools and packages. Experience the classic desktop environment reimagined for the modern web.

[Visit GnrllyBttr.dev →](https://gnrllybttr.dev)

## ✨ Features

- Windows 95-inspired interface
- Draggable window functionality
- Interactive desktop elements
- Responsive design
- Retro animations
- Dark pattern background
- Status bar with live updates

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## 🤝 Contributing

We welcome contributions! Here's how:

4. Commit your changes

### Coding Standards

- Use 2 spaces for indentation
- Follow semantic HTML5 markup
- Keep JavaScript vanilla
- Maintain responsive design
- Document complex functionality

## 🐛 Issues
